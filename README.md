# Portfolio

Sanket Pawar's portfolio as a tiny planet you can walk around. Each place is a project: My story, CIIE.CO, Ascend, Skillay, and a Playground that holds Job Hunter 2026. Deliver the letter to the house with the smoke to reach me.

**Play it:** https://sanketp9499.github.io/Portfolio/
**Classic site:** https://sanketp.webflow.io

## How to move
- Arrow keys or W A S D, or hold the mouse button, or click where you want to go.
- E opens a place, Space turns the page.
- The sky follows your local time. Day and Night buttons override it.

## Built with
A single HTML file and Three.js r128 from cdnjs. No build step. Images live in `assets/`.

Designed by me and built with AI tools (Claude Code).
